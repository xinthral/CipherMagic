# CipherMagic

While working through the Ceasar Cipher with the Vignette modifications I found that the algorithm
wasn't very complicated, but the implementation did require a fair amount core implementation techniques
to get working properly. String manipulation, 2D arrays, query by indeces, as well as the actual algorithm itself which performs a hashing/dehashing of an input based on a salt, and offset by a key.

Each Language has it's own nuances that required it's own unique solution to solve, so performing the same known algorithm for each language was an exercise in adherence design paradigms and syntax exploration. Learning does not require purpose, only ambition.
